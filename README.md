# HTML to Markdown Desktop Converter

Aplicación de escritorio ligera y rápida desarrollada en **Go (Golang)** utilizando el framework gráfico **Fyne**. Permite convertir código fuente HTML completo (como el obtenido desde la opción "Ver código fuente" de cualquier navegador) en un formato **Markdown** limpio y estructurado de forma instantánea.

---

## 🛠️ Tecnologías utilizadas

* **Go** (Golang)
* **Fyne** (`fyne.io/fyne/v2`) para la interfaz gráfica de escritorio.
* **html-to-markdown/v2** (`github.com/JohannesKaufmann/html-to-markdown/v2`) para el motor de conversión.

---

## 📋 Requisitos previos

* Tener instalado **Go** (versión 1.18 o superior recomendada).
